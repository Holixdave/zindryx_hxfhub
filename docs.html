How invite links work

What does an invite link share?

Only your group's name, photo, and member count are shown before joining — never message content, unless the group admin turns on message previews for that specific link.

Can I control what a new member sees?

Yes. When generating a link from group info, you choose an expiry (up to 7 days by default, shorter if you like) and whether new joiners can see messages sent before they joined. Turning that off doesn't delete anything for existing members — it only hides history for the new person.

Where is my data stored?

Messages and group data are stored on Firebase Google Firestore. Invite links are validated and joins are processed directly against Firestore's security rules — Zindryx doesn't run a separate server that touches your messages.

Can a link be canceled early?

Yes — the group admin can revoke a link at any time from group info, even before it expires.
