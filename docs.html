Invite links

How invite links work

To join a group on Zindryx you need an invite link. An invite link looks like linking.chadivavirtuals.name.ng/?code=abc1234. The code is 7 letters or numbers. Opening the link on a phone with Zindryx installed opens the app and shows the group with a Join button. Without the app, the website handles it.

What a link shares

Before joining, you only see the group's name, photo and member count. Never message content.

What admins control

The expiry (up to 7 days by default), whether new members see earlier messages, and revoking the link early.

If a link doesn't work

No code detected: the link had no code. Invalid code: no invite with that code exists, so check for a typo. Expired: it passed its expiry date. Revoked: the admin cancelled it. For the last two, ask the admin for a new link.

Same idea for calls

You decide who can add you to groups and who can call you. Set it to nobody and no one can add you without your consent.

Features

Everything you need to prepare

Three big ideas sit at the centre of Zindryx. Around them are the tools that make studying easier.

Pillar 1

Synced CBT exams

Studying and answering questions alone can leave you behind. So Zindryx has a synced exam system: several students practise the same questions together, in real time, in one practice room.

  • Start one from any group chat. Pick the subject, difficulty, number of questions and how it plays. OOOR makes fresh questions for every session
  • Two ways to play: Race (everyone goes at their own speed with live scores, and the first to finish gets a bonus) or Quiz night (everyone sees the same question at the same time, then the answer is revealed together)
  • Chat, send voice notes and fire off reactions while you practise
  • Fair scoring: 100 points × difficulty per right answer, up to 50 more for speed, and +20 once you get 3 right in a row
  • The host can mute voice, drop someone from the exam or report them

Safety and privacy

A study space you can trust

Students should be able to chat without being spammed, scammed or added to places they never agreed to. Here's how Zindryx protects you.

You control who gets to you

  • Add-to-group control. In Profile and privacy settings, choose who can add you to groups. Pick nobody and you can't be added without consent.
  • Invite links. Groups need an invite link to join. Calls follow the same idea: you choose who can call you.
  • Message requests. Non-friends must send a request and can send only two messages until you accept.
  • Report button. Easy to reach whenever someone acts suspiciously.

Shadow-ban service

If an account keeps acting fraudulently and gets reported several times, it is blocked. Their messages are then visible only to themselves. No one else sees them. The block stays until our server unblocks the account.

FAQ

Questions people ask

Which exams is Zindryx for?

JAMB and WAEC. It started for JAMB students and now covers secondary school standard education. It is not for Post-UTME.

Which subjects can I practise in a synced exam?

Mathematics, English Language, Physics, Chemistry, Biology, Economics, Government, Literature in English, Commerce, Geography, CRK and Further Mathematics. You can also add an optional topic, like quadratic equations.

I'm in a higher institution. Can I use it?

You can use the platform areas, like chat and calls, as a study-focused space. We don't guarantee learning content for higher-institution courses.

Is Zindryx on the Play Store?

Not yet. For now you can download the app directly from the download page, where every version is listed.

Can I practise without internet?

Yes. Download questions while you're online, then practise offline later. It also saves your data.

What does an invite link share?

Only the group's name, photo and member count are shown before joining. Never message content.

Can a link be cancelled early?

Yes. The group admin can revoke a link at any time from group info, even before it expires.

My code says "invalid", "expired" or "revoked".

Invalid: no invite with that code exists, so check for a typo. Expired: it passed its expiry date. Revoked: the admin cancelled it. For expired or revoked links, ask the group admin for a new one.

The site says "No code detected".

The link had no invite code. Paste your code on the home page, or ask the admin to send the link again.

Where is my data stored?

Messages and group data are stored on Google Firebase Firestore. Invite links are checked and joins are processed against Firestore's security rules. Read our Privacy Policy and Terms & Conditions for details.

What is OOOR?

OOOR stands for Out Of Ordinary Response. It combines several large language models working together to give the best result in the most efficient way.

Why am I seeing messages from a blocked person?

You aren't. Accounts blocked for fraud have their messages shown only to themselves. If you see someone behaving badly, use the report button.
